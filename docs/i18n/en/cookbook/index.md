---
title: Cookbook
description: Small, runnable Loxia programs for common tasks.
---

The cookbook collects complete programs, not fragments. Each recipe is based on a file in
`exemplos/` and is kept runnable by the documentation tests.

- [Fibonacci](fibonacci/) — recursion and an iterative version.
- [Classes and inheritance](classes/) — constructors, fields, overriding and `super`.
- [Quicksort](quicksort/) — typed lists, indexing, `push` and recursion.

Every recipe is a complete program and is executed by the documentation tests. The
[examples directory](https://github.com/loxia-lang/loxia/tree/main/exemplos) has the
original files the recipes are based on.
