**Loxia** is a language for people who want a small, predictable language descended from
Lox without giving up static checking, deterministic diagnostics or a native backend.

The tree-walk interpreter is the executable specification. The optional LLVM backend is
tested to produce the same stdout, stderr and exit code on a declared corpus.

<CardGrid>
  <Card title="Executable specification" icon="open-book">
    The interpreter is the oracle. Every feature has a golden case, and the differential
    corpus compares interpreted and compiled execution byte for byte.
  </Card>
  <Card title="Two engines" icon="rocket">
    Start with the interpreter, then compile to a native binary with the optional LLVM
    backend. The same checker types feed both engines.
  </Card>
  <Card title="Nothing implicit" icon="approve-check">

  </Card>
  <Card title="Batteries included" icon="puzzle">
    JSON, CSV, paths, files, processes, collections, hashing, property-based testing and a
    real test runner are part of the standard library.
  </Card>
